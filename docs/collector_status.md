# Стан збирача

Реалізовано вибір за найновішою датою назви, перевірку дати всередині Excel, SHA-256, порівняння рядків, архів оригіналу та атомарне перемикання current.json. Дані зберігаються у версіях data/snapshots/<sha256>; поточний CSV визначається через data/current.json. Розклад і запис з Actions до репозиторію ще не налаштовані.

Локально пройшли 23 контрольовані тести. Тимчасові CSV перевіряють логіку рядків; вони не замінюють інтеграційну перевірку XLSX.

Перевірка реального файлу 01.09.2026 виявила 14 повторених ключів, з них 8 із різними значеннями. Див. source_duplicates.json. Збирач навмисно відхиляє такі дані; вибирати перший/останній рядок або сумувати їх не можна без визначення причин. Початковий тест доступності перевіряв колонки, але не унікальність спостережень.

Наступний крок: з’ясувати конфлікти джерела, узгодити явні виправлення або отримати виправлений файл; після цього перевірити повний ручний запуск. Дані для дашборду не опубліковані.

Локальний запуск: python -m scripts.collect_nerc
Тести: python -m unittest discover -s tests -v

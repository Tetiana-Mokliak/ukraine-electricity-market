# Ukraine Electricity Market

Дослідження місячної динаміки ринку електроенергії України: імпорт/експорт, середньозважені ціни, структура виробництва та споживання, частки ВДЕ.

## Поточний стан

Реалізовано контрольований ручний збір: пошук найновішого XLSX, архів оригіналу, погоджені адресні реконструкції, перевірка унікальності та порівняння версій. Додано автоматичний збір у GitHub Actions: щодня о 07:17 UTC, із записом у main тільки прийнятих змін. Power BI ще не підключений.

16.10.2026 успішно виконано повний ручний збір файлу від 01.09.2026. Прийнято 4566 рядків; усі 162 місячні підсумки імпорту/експорту точно узгоджуються. Перевірено аудит, оригінал і повторне приймання незміненого файлу. Пройшли 48 локальних тестів.

Поточну версію визначає [`data/current.json`](data/current.json); CSV і аудит розміщені у відповідному `data/snapshots/<sha256>/`. Оригінал також зберігається в `data/raw/<sha256>/`.

- [Правила й обмеження реконструкцій](docs/corrections.md) — це припущення проєкту, а не офіційні виправлення НКРЕКП.
- [Підсумок перевірки та ручного збору](docs/collector_status.md).
- [Зовнішня перевірка серпня 2022](docs/diagnostics/2026-10-16-august-2022.md).
- [Фінальна діагностика всього джерела](docs/diagnostics/2026-10-16-final.json).

Відсутні записи країн не замінено нулями. Точні суми не доводять повноти розподілу чи незалежної достовірності джерела. Історичні діагностичні файли описують стан на відповідному етапі; актуальний стан наведено вище.

## Автоматичне оновлення

Workflow `Update NERC data` перевіряє сторінку щодня о 07:17 UTC (час старту в GitHub може затримуватися), а також після змін коду збирача. Ручний запуск: Actions → Update NERC data → Run workflow.

Вміст Excel порівнюється за SHA-256, а не лише назвою чи URL. Однаковий файл → без нового знімка й коміту. Новий вміст → архів, погоджені правила, перевірки структури, ключів, кварталів, точних торговельних сум та порівняння версій. Лише після успіху оновлюється `data/current.json` і створюється коміт. Якщо зникли попередні ключі або є інша помилка — поточна версія залишається, запуск завершується помилкою. Нові реконструкції автоматично не вигадуються.

Повернення до раніше архівованого вмісту після іншої прийнятої версії потребує перевірки; історичний аудит не перезаписується. Якщо змінено байти Excel, але записи ті самі, новий оригінал зберігається з позначкою `file_only_change`.

Аудит запуску та відхилений оригінал доступні в артефактах Actions 14 днів. Для незміненого файла зберігається лише короткий результат запуску, без нових копій Excel у репозиторії. Локально пройшли 54 тести; реальний XLSX перевірено в ізольованому прийманні та повторному запуску.

## Запуск

Ручний збір: `python -m scripts.collect_nerc`.

Тести: `python -m unittest discover -s tests -v`.

Actions → Test NКРЕКП source → Run workflow — окремий тест доступності та структури джерела, який не публікує робочі дані. Локальний збирач обирає найновішу дату назви файлу; за неоднозначності або невідповідності структури відхиляє результат. Попередня прийнята версія зберігається.

## English

Monthly Ukrainian electricity market research covering trade flows, prices, generation and consumption mix, and renewable energy shares.

Controlled manual collection, revision comparison, source archiving and explicitly reviewed analytical corrections are implemented. On 16 October 2026, a complete manual run accepted 4,566 observations from the workbook dated 1 September 2026; all 162 monthly trade totals reconcile exactly and 48 local tests pass. A daily GitHub Actions check at 07:17 UTC is configured, committing only validated source changes; unchanged SHA-256 creates no new snapshot or data commit. Missing country records are not imputed as zero; corrections are project assumptions, not official NERC amendments.

## Таблиці для Power BI

`python -m scripts.prepare_power_bi` читає прийнятий знімок через `data/current.json` і формує CSV у `data/power_bi/`. Workflow запускає підготовку після успішної перевірки джерела, зокрема коли джерело незмінне, але змінено код перетворень. Коміт даних створюється лише за зміни вмісту. Помилка підготовки блокує коміт даних цього запуску; опубліковані файли залишаються попередніми.

- `trade_countries.csv`: дата, напрямок, країна, обсяг; без «усього».
- `trade_coverage.csv`: кількість наявних країн і ознака підтвердженого нульового підсумку; це не гарантія повноти країн.
- `market.csv`: дата, сегмент, обсяг (тис. МВт·год), ціна (грн/МВт·год).
- `green.csv`: дата, група виробників, придбаний обсяг, тариф (грн/кВт·год).
- `generation.csv`, `consumption.csv`: місячні частки за категоріями.
- `renewables.csv`: частки кожного типу серед ВДЕ та в загальному виробництві.
- `calendar.csv`: один рядок на місяць, дата першого числа, рік, номер/назва місяця, квартал. Це місячний довідник; для стандартної time intelligence у Power BI може знадобитися окремий щоденний календар.

Перетворення перенесено з навчального ноутбука користувачки: прибрано дослідницькі виводи, дата формується один раз лише для відібраних місячних показників. Перевіряються ключі, пропуски, одиниці, суми структур та узгодження двох представлень частки ВДЕ. Допуск часток — 0.000001 відсоткового пункту, без зміни значень; він не змінює точних правил торговельних реконструкцій. Відсутність рядка країни не заповнюється нулем. Відсотки залишаються у шкалі 0–100; ціни й частки не можна довільно підсумовувати за місяцями.

Power BI ще потрібно підключити до сталих raw-адрес цих CSV та окремо налаштувати оновлення моделі. CSV зберігаються в UTF-8 з BOM, дати — YYYY-MM-DD. Вихідний Excel і погоджені реконструкції не змінюються цим скриптом.

## Energy Map: відключення як контекст

Додано [щомісячний збір Energy Map](docs/energy_map.md): 5-го числа о 08:37 UTC,
один запит завантаження, без автоматичних повторів. Оригінал порівнюється за
SHA-256; незмінний файл оновлює лише метадані успішної перевірки. Початковий
знімок отримано 21.10.2026, остання дата записів — 30.06.2026.
Для автоматичного доступу потрібно додати Actions secret `ENERGY_MAP_TOKEN`.

створює [очищений CSV](data/energy_map/processed/outages.csv) та аудит.

# Погодинна торгівля Energy Map: стан збереження

Код, 212 правил очищення  збережено в цьому
каталозі та scripts/. Готова таблиця перевірена локально: 753153 рядки,
69 без однозначного UTC; решта значень і добові суми збережені.

**Стиснені файли таблиці ще не перенесені в main.** Повний комплект підготовлено
окремим архівом з відносними шляхами цього репозиторію. До завершення передачі
current.json у цьому каталозі не публікується.

Для завершення потрібно розмістити з архіву весь каталог
snapshots/427d106ca6ebb3d1be83e24c/ разом із current.json. Спочатку перевірити
контрольні суми всіх файлів, потім додати покажчик. Коміт має містити весь комплект.
Для локального використання досить розпакувати архів у копію репозиторію.

Обробник може також відтворити результат з оригінального перевіреного CSV:

```bash
python -m scripts.prepare_hourly_trade /path/to/energy_map.csv
```

Безпека публікації: у комплекті тільки дозволені значення Energy Map, код і
позначки приватності; немає XML, токенів або числових витягів ENTSO-E.
Методика: ../../docs/hourly_time.md. Підсумок: ../../docs/hourly_trade_research.md.

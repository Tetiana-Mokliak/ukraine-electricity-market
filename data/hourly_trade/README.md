# Погодинна торгівля Energy Map

Код, 212 правил очищення, готова таблиця й аудит збережені в main.
753153 рядки, 69 без однозначного UTC; решта значень і добові суми збережені.

Поточний знімок визначає [current.json](current.json):
`snapshots/427d106ca6ebb3d1be83e24c/`.
Авторка завантажила current.json та всі вісім файлів знімка вручну 01.11.2026,
коміт a80368a7e04c322a9173908b89872f9b262368f4. Всі дев'ять Git blob SHA-1
збіглися з підготовленим архівом; файли й шляхи перевірені.

Основна таблиця — [trade.csv.gz](snapshots/427d106ca6ebb3d1be83e24c/trade.csv.gz).
Вона містить тільки значення Energy Map. XML, токени та числові витяги ENTSO-E
до комплекту не включені. Поточний snapshot також зберігає вхідний CSV, реєстр
історії, журнал вилучень, невизначені записи, неповні доби, аудит і зміни.

Обробка без мережі:

```bash
python -m scripts.prepare_hourly_trade /path/to/energy_map.csv
```
